# Adaptive research routing

Use this reference to select one next action. Do not run every row.

## Route by the current bottleneck

| Current bottleneck | Use | Exit evidence |
|---|---|---|
| Destination, scope, or trade-off is a human choice | `$research-grilling` | one accepted or proposed decision record |
| Terms, constructs, units, or relations collide | `$research-domain-modeling` | current domain map and glossary |
| A factual premise or source claim is uncertain | `$evidence-research` | claim chain with exact status and locator |
| The field boundary is unclear | `$literature-landscape` | mapped theories, methods, data, findings, and disputes |
| Novelty or “no one has done this” is claimed | `$gap-audit` | surviving, failing, or blocked gap verdict |

## Preserve interaction behavior

- Investigate facts; ask the user for decisions.
- Ask one dependent question per exchange.
- Include a recommendation and its cost.
- Persist the answer before asking another.
- Recompute the frontier after new evidence or a user exclusion.
- Prune irrelevant routes. A completed route does not justify running adjacent skills.
- A negative result may complete a research task even when it kills the design.

## Handle common starting points

### Vague topic

First clarify the intended phenomenon and destination. Then map only enough literature to expose the closest viable questions.

### Imported theory, equation, or method

Clarify semantics before application. Search prior uses, test whether the analogy changes an inference, and identify data capable of distinguishing it from ordinary alternatives.

### Data-first request

Inspect real data semantics and access before promising a question. Derive the strongest inference the data can support.

### Existing plan or proposal

Pin the artifact. Diagnose its current bottleneck and preserve accepted choices. Do not restart ideation unless a load-bearing review finding requires it.

### Existing results or manuscript

Separate observed results from interpretation. Audit identification, citations, internal consistency, and missing negative evidence before rewriting.

## Escalate context deliberately

When the unresolved decision tree cannot fit one session, write a research map with destination, decisions, frontier, fog, artifact pointers, and next question. End the session at a real decision boundary and create a read-back handoff. Do not copy the entire conversation into the map.
