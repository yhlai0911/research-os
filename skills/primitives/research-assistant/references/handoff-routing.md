# Workflow routing reference

The current routing contract is [workflow-delegation.md](workflow-delegation.md). Read it for a natural-language research mission, an explicit workflow transfer, or a returned result that needs the next step.

The assistant selects and delegates; the receiving skill performs the research and returns its own question, artifact and gate. A novice does not have to type every skill name. Preserve `research-help` as recommend-and-stop, direct named entrypoints, actual research decisions and exact authority boundaries. A prepared route is not execution evidence.
