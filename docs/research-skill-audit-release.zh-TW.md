# 研究技能交接修補

這次核心修補處理可修訂題名與 mission 延續、資料先行預檢、status 對正文／審查 verdict 的核查、無效啟發式的適用邊界，以及審查後真正修稿與比較回程。一般版保留跨學科用途；學位與學科要求只在適用時使用。

修補基底為 `56159bb46194f513d4e4499f228abf3ad6455cb1`；核心變更涉及 15 個技能／隨附契約或模板檔案。這不是 42 個技能全部改寫，也不是已完成一篇論文的證明。

本機原始稽核保留 36 次模型案例，歷史為 26 pass／10 fail；15 個主要情境的指定行為最後一筆通過，另有原版明確要求題名的正對照通過。失敗與中間修訂沒有刪除。測試使用本地合成案例，不含真正研究個案；全文文獻、實際修稿與回程另做有界補測。模型沿用 `gpt-6.1-sol`、`high`、`default`；各次速度是含工具的牆鐘時間，不能當生成吞吐量。

本修正分支不收錄原始模型對話、個案資料、個人路徑、憑證、全文文獻或影片。原技能來源與已執行研究包保留；其他來源的學術 companion 另作本機增量補丁與來源紀錄，不當作本 repo 自有技能。

採用後仍須以這次研究的真實資料與版本跑完整鏈，逐階段核對產物，最後驗收草稿。具體步驟見 [全流程與五章驗收清單](end-to-end-acceptance.zh-TW.md)。未完成真實估計、真人新手研究或全面文獻核查，不得因技能測試通過而宣稱已完成。
