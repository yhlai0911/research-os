# Language / 語言

Research OS supports English and Traditional Chinese explanations and research artifacts. Follow an explicit language request; otherwise match the user's current language. Ask only when the intended audience's language is genuinely unclear. Reusable skill instructions remain concise English.

Research OS 支援英文與繁體中文說明及研究成果。優先遵從明確語言要求，否則配合使用者當前語言；只有成果受眾的語言不明時才詢問。可重用 skill 指令維持精簡英文。

- Keep skill names, commands, paths, artifact IDs and machine-readable status/schema values unchanged. 保留技能名稱、指令、路徑、ID 與機械狀態值。
- Preserve source quotations in their original language; label translations and retain citation provenance. 原文引述保留來源語言，譯文須標明，引用來源不因翻譯而改動。
- Bilingual explanations should not duplicate canonical artifacts or create a competing current brief. 雙語說明不代表建立兩套互相競爭的正式研究文件。

Examples / 範例:

> Explain the next step in English; keep the existing brief in Traditional Chinese.

> 請用繁體中文說明風險，最後附英文摘要；保留原有 claim IDs。
