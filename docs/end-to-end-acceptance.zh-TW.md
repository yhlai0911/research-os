# 研究先驗收，再採用錄影素材

本清單供完整研究流程使用。通用研究依目的選用階段；五章要求只適用於明確要求五章草稿的學位案例，不把財金、學位或影片需求加入一般研究契約。錄影是過程證據，不能反過來決定研究題目、資料或結論。

## 版本化採用

1. 保存舊研究包、原對話、已用技能、安裝收據與已凍結估計。記錄來源 commit／hash，不覆寫或追認舊版本已具新功能。
2. 在自然交接窗口建立新的可寫續作副本，記錄 `continuation of`、研究來源版本、技能來源 commit、採用時間與改動影響。任何新結果均屬新版本。
3. 檢查 config 與 adapter 的絕對路徑，確保所有輸出寫入續作副本；舊來源可只讀引用。不可讓修稿回寫舊凍結包。
4. 從指定修正 commit 安裝到全新候選目錄，執行 `verify_install.py`。比對舊模板，只在續作副本補必要欄位；不熱換正在執行的 session。
5. 新 session 讀回實際 Brief、index、reviews、claims、執行收據與輸出檔，確認實際讀到新版技能，才接回下一個必要階段。不得因升級技能而自動重跑已凍結結果或更換研究門檻。

## 每階段的共同驗收收據

逐階段保存：輸入 ID／版本／hash、實際 prompt、模型與 effort／service tier、追問與答案、技能來源、真正執行的命令與回覆、輸出 ID／路徑／hash、證據限制、判定、未解 finding、下一步與責任角色。程序退出成功、檔案存在、腳本完成或回覆「已修改」，都不單獨構成研究通過。

錄影任務另存素材索引：實際時間、畫面／日誌來源、所示產物版本、對應階段、是否呈現失敗與修復。不得重演後冒稱原始執行。若研究失敗，素材保留為除錯紀錄；只有對應研究品質通過後才列可剪素材。兩種狀態分開登記，影片不改寫研究 mission。

## 階段與產物

| 階段／必要入口 | 必須真正產出的材料 | 通過條件與不通過時的回程 |
|---|---|---|
| 工作區與分流：workspace-contract、triage／map | 唯一 canonical config/index、既有材料盤點、當前瓶頸 | 已題名／資料／初稿從現有產物進入，無資料先預檢存取；不重複問已知資訊，不重開選題。索引與正文衝突先 reconciliation |
| 問題釐清：1-grill | 有界問句、目的、推論類型、限制、可修訂題名與接受狀態 | 資訊不足先問最有影響的一項，允許題名未定；方向清楚後才給暫定題名。不把課程／影片目的當研究需求 |
| 證據與 Brief：2-brief、evidence／literature／data skills | 原始來源矩陣、主張鏈、資料存取與單位／時點紀錄、單一 Brief | 文獻存在、版本與內容支持分開核查；保留矛盾及不可得來源。真實資料要可取得，單位用文件／轉換／對齊核實，失效啟發式不是事實 |
| 可否證與方法：3-falsify、適用 primitives／選用 profile | 競爭解釋、事前基準、失敗／停止條件、資料與方法定義 | 不能改門檻求顯著。因果、預測、描述用各自適當標準；不強迫套用不相關 GMM、實驗或特定學科要求 |
| 執行計畫：4-tasks、to-plan（需要時 proposal） | 有依賴、owner、輸入、驗收與停止條件的可執行工作包 | 規劃保持 proposed，未取得資料／未跑程式不得完成化。文件與 canonical index 同步；一份文件不擅增多受眾版本 |
| 真正執行：5-run | 資料版本、清理與對時、程式／環境、逐次執行、結果／失敗／圖表 | 必須真的執行、重算並讀回。示例或合成結果只證明流程，不作市場／人群實證。保留負結果、未顯著、估計失敗及排除理由 |
| 草稿：to-paper、research-writing | 來源可追的完整草稿、表圖、限制；學位案例依下表五章驗收 | 結果均可追到實際執行；沒有結果只能交藍圖並列缺口。引用、表格、摘要與結論一致；不得捏造章節、分析或數字 |
| 審查與實際修訂：6-review、適用 companion、writing | 固定 target/base、穩定 finding ID、實際修稿、逐項回覆、比較包與複核 | 先看正文差異，再判 finding 是否解除。所有比較軸使用同一 base/target/packet。回覆信不等於改稿，文字修正不等於方法或估計已修復 |
| 最後 readback：status、review | 當前五章／稿件、索引、證據、執行、審查與未解清單 | 所有影響主要結論的問題已解除，或清楚降格且不超出證據，才能判目前草稿品質通過。不得以平均分掩蓋關鍵缺陷 |

「所有環節」指被實際研究需要的完整鏈，並非強制每篇研究呼叫全部技能。每個適用環節均須有真實輸入、產物與判定；不適用項記理由，不冒充已測。

## 五章草稿驗收（只在使用者明確要求時）

| 章 | 核對內容 | 不可接受的替代 |
|---|---|---|
| 第一章：問題與貢獻 | 題名與問句一致、目的與範圍清楚、貢獻有邊界 | 只有問句沒有題名狀態；把教學目的當研究價值；未證實的「首次」 |
| 第二章：文獻與理論 | 一手全文、準確版本與定位、真正的爭點與相反證據 | 只讀摘要或書目就驗證主張；只有逐篇摘要；捏造引用或全文內容 |
| 第三章：資料與方法 | 定義、單位、樣本／時點、可得性、模型／基準、推論與失敗條件可重做 | 設計草案寫成已執行；未驗證來源；隨機切分／事後選模未揭露；未定義符號 |
| 第四章：結果與討論 | 每表每圖可重算、摘要數字對得上、完整報告不利結果、推論不超出設計 | 用示例／合成測試填市場結果；刪負結果；只交分析計畫；無程式或執行收據 |
| 第五章：結論與限制 | 直接回答原問句，統計／實務／因果界限準確，限制與後續可執行 | 新增未分析的發現；「不顯著」寫成等效／完全無效；從預測誤差跳成可交易獲利 |

完成五個章名不是完成草稿品質驗收。章間還須核對題名／變數／樣本／數字／引用／狀態一致，審查發現已實際改回正文，且能由保存材料重算主要結果。

## 剪片前的放行

研究任務先交付逐階段收據、五章成稿與複核結果；影片任務讀取同一固定版本後，才決定素材可用。仍有主要結論無證據、無法重算、引用不支持或必修 finding 未關閉時，影片成片狀態維持 pending。不能用技能回歸通過代替此特定論文的全流程驗收。
