# 學術正文與跨語言清晰寫作

這次把學術寫作的預設要求接到寫作、研究交付與全文審查入口：正文要形成連貫論證，句子清楚、術語一致，並保留證據的不確定性。使用者不必每次重貼寫作風格提示。APA 為未指定格式時的預設；使用者、學校或期刊提供的格式優先。

## 修改範圍

共同規範放在 `skills/primitives/research-writing/references/academic-prose.md`，由下列三個入口引用：

- `skills/primitives/research-writing/SKILL.md`：寫作與改稿前讀取。
- `skills/primitives/render-research-deliverable/SKILL.md`：研究計畫、提案、論文藍圖與稿件套用。
- `skills/primitives/research-review/SKILL.md`：全文審查時檢查，缺陷須附位置、修正與驗收條件。

`to-paper` 原本即委派給 renderer，`research-6-review` 原本即委派給 reviewer，因此沒有複製一份容易失同步的規範。這兩條委派路徑只做靜態核對，這輪未另跑完整 orchestration。

首輪行為測試另抓到英文審查的一項回流建議：它要求修訂稿回到首次全文審查，與既有 comparison 規則矛盾。已在 reviewer 的修正清單要求中補明：實際修改受審產物後，須固定原版與修訂版，以 comparison 模式回審。這是對既有規則的明確化。

## ASD-STE100 的採用界線

2026-10-18 核對 ASD Simplified Technical English Maintenance Group 的[官方 FAQ](https://www.asd-ste100.org/STE_faq.html)與[官方介紹](https://www.asd-ste100.org/)。官方說明包含受控英語、寫作規則與字典，也容許在其他寫作情境採用有益的清晰原則。本次只借用明確指涉、直接表達、用語一致及避免歧義的精神；未取得或實作整部標準，也不宣稱合規或認證。

共同規範適用各語言的學術正文。必要的專業名詞、語氣保留、限制、引用、表格、公式、假說與有順序的方法步驟都應保留；審查報告仍可用 finding ID、修正表與清單。英文受控字典、固定句長與中文每句字數上限不作為學術驗收門檻。清楚的文字也不能把相關變成因果，或把未顯著結果改寫成效果等於零。

## 本輪驗證

行為測試使用四個全新隔離工作區，分別測試繁中寫作、英文寫作、繁中全文審查與英文全文審查。一般改稿／審查提示未重述新風格規範；測試直接呼叫選定 skill，觀察其預設行為。輸入是合成教學紀錄，並非真實受試者研究或其他任務的論文成果。

每份輸入包含同一組保存欄位：`n=120`、`beta=0.02`、`95% CI=[-0.05,0.09]`、`p=0.57`。方法明說未重算估計，`heteroskedasticity-robust` 只是供件方法標籤。原討論段刻意放入投影片式碎句、因果主張、未顯著即無效果，以及憑句長和刪術語即可取得 ASD-STE100 認證等錯誤。預期寫作要實際改稿，審查要指出具位置與驗收條件的修正，兩者均不得捏造實證結果。

## 採用方式

從本 PR 的確切 commit 取用上列三個 `SKILL.md`，以及共同規範 `research-writing/references/academic-prose.md`，四個檔案一起更新。也可在獨立 checkout 切到該 commit，沿用 repository 原有安裝流程。先比較目的端的本機修改，遇到衝突即保留並人工整合；不要覆寫正在執行的研究工作區。
