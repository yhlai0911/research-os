# 研究助理：全程都能叫出的陪跑者

`research-assistant`替你選擇Research OS技能，並引導你經歷各個流程。它先辨認需求與目前成果，將任務交給適用skill，由該skill實施研究，再讀回產出、說明改善與下一步。它不把所有研究工作包進自己，也不要求新手先知道每個skill名稱。`research-help`則維持只推薦入口後停止。

## 直接這樣說

| 你需要什麼 | 可以貼的話 |
|---|---|
| 完全沒有題目 | 「我想寫論文，但完全沒有題目，應該從哪裡開始？」 |
| 指引 | 「當我的研究助理，先讀這個專案，告訴我現在卡在哪、下一步怎麼做。」 |
| 建議 | 「我已有資料和草稿，請比較兩種下一步，建議一個並說明取捨。先不要改檔。」 |
| 範圍內代決 | 「只檢查這份本地 CSV 的欄位；解析方式由你決定，說明理由。不改原始資料，不跑模型。」 |
| 已授權執行 | 「請在這個測試專案內檢查資料筆數與缺漏，整理一份可核對的檢查結果。方法由你決定；保留原始資料，不跑模型、不連外。」 |
| 續做 | 「從這個專案的交接紀錄接續，先核對成果與待辦，別重問已決定的研究方向。」 |

Codex 也可明確使用 `$research-assistant`。自然語句能否自動選到它，仍取決於工具是否已讀入技能與實際選擇；安裝檢查通過不代表已完成自動觸發實測。Claude Code 由對話選用這個助理，不新增斜線選單入口。

## 它會先確認什麼

有專案時先依專案設定讀取目前研究紀錄，進度以成果與執行證據為準。有多個專案會先釐清目標；資料互相矛盾時會指出兩邊來源。沒有題目時會選用`research-1-grill`釐清背景與興趣，不偷帶舊題目、資料或方法。尚無研究紀錄時，只有在已授權本地建檔的範圍內才先交給`research-setup`建立空白紀錄；否則仍可先給指引。

在 Codex 開啟已安裝 Research OS 的研究專案，輸入 `$research-assistant` 與上面任一需求。助理已在 `main` 的核心清單與同一套安裝器內，不需另裝旁掛技能。若找不到它，先核對來源 commit、目標 `.agents/skills` 與當前專案，再依宿主支援方式更新清單。安裝檢查或手動閱讀規範都不等於原生載入成功。

重要研究選擇仍由你確認，例如問題、假設、樣本排除、推論強度與推翻假設的條件。明確授權內的可逆技術選擇可代決並說明理由。單純翻譯、潤稿或排版不應啟動整套研究流程。

## 用閱讀頁看結果

可以直接說：「研究助理，請把已完成的比較表和結果段落做成可排序、可篩選的閱讀頁，讓我看圖和修訂對照；保留原稿。」助理會實際產生頁面，確認連結可開啟，再用簡短說明、產物連結和下一步回覆。表格中的原始值、單位與來源仍會保留；沒有兩版文字就不會捏造修訂對照。

頁面內的比較表、圖表、段落與返回連結都能實際操作。本機檔案或本機預覽只供同一台電腦使用；需要跨裝置時，須透過當前介面支援的附件交付。尚未產生、缺檔或無法交付時，助理會直接說明，不會給假的連結。這是閱讀輔助，論文正文、引用與LaTeX PDF規格照原要求。

## 主線交接

用戶委託研究協助後，助理會依真實狀態選擇並交接適用skill，不要求你逐一鍵入技能名稱。交接包括原始需求、現有成果、授權範圍、待答問題與完成條件。接到任務的skill必須真的讀取規範並完成自己的工作，不能只把推薦文字說成已執行。直接使用`$research-1-grill`等既有入口仍可用。

每一步先看這個skill解決什麼缺口、如何使用，再看真實產物有什麼變化、哪個條件滿足才能前進。研究選題由grill釐清，資料/分析/寫作/審閱由適用skill實施，助理負責帶路與核對。缺資料或必要決策就停在該關卡；不因寫了文件就假稱能進下一步。`research-auto`仍是可明確選用的另一種整合流程，助理不取代它。

原生技能工具可用時使用其正式入口；目前工作環境未提供原生介面時，可明記為「完整讀取規範後的交接執行」，不能冒稱原生載入或繞過被拒操作。安裝與本地預檢只證明相依與路徑，不能代替真正行為驗收。

「幫我」「繼續」「你決定」不等於允許大量運算、付費、外部寫入、寄信或投稿。先前失敗或沒有顯著結果也要保留，不能事後偷改假設。文獻與證據查不到就標示未驗證。

可選專案範圍或刻意選用個人安裝；既有副本不會因遠端合併自動更新。操作範例見[短文字示範](RESEARCH_ASSISTANT_DEMO.zh-TW.md)，工具與成果規格見[閱讀頁與學術交付](DELIVERABLES.zh-TW.md)，各層驗證見[驗證流程](RESEARCH_ASSISTANT_TESTING.md)。[English guide](RESEARCH_ASSISTANT.en.md)。
