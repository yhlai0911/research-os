# 用研究助理從沒有題目走到成文：銀行行銷範例

[影片、30頁PDF與來源包](https://github.com/yhlai0911/research-os/releases/tag/bank-term-deposit-tutorial-v1) · [研究索引與校驗](../examples/bank-term-deposit-marketing/README.zh-TW.md) · [English](TUTORIAL_BANK.en.md)

先依[使用教學](USAGE_GUIDE.zh-TW.md)安裝到自己的研究專案。對研究助理說：

```text
$research-assistant
我想寫商管財金碩士論文，但完全沒有題目，應該從哪裡開始？
```

不必先選本片的題目。影片用教學角色示範研究如何逐步形成；你的背景、資料與重要決策應以自己的情況回答。助理選擇並交接流程，具體研究由接收 skill 執行。

|你目前的問題|適用skill與可觀察效果|接著怎麼做|
|---|---|---|
|完全沒有題目|research-assistant 交接 research-1-grill，從經驗與困惑開始|回答一個當前真正需要的背景／目的問題|
|想法聽起來合理，但還不知道能否研究|data-feasibility、literature-landscape 等核對資料版本、欄位與最近研究|讀實際來源與候選比較；證據不足就修題或轉向|
|題目逐漸清楚，方法還沒對齊|research-2-brief 與適用設計技能收斂問題、資訊、樣本、方法與界線|確認設計能回答原問題，不能把提案當已完成結果|
|怕看完結果才改說法|research-3-falsify 先列反證，再由 research-4-tasks 定完成條件|核對事前比較、主次條件及停止門檻|
|準備做一段研究|research-5-run 依已確認規則產生可核對結果|從回覆的真實連結開表格；需要時排序、看圖，再回研究判斷|
|結果可以直接寫進論文嗎|research-6-review 找出同版缺漏並要求修正|保留例外與反證；未通過的主張不要寫成定論|
|資料和結果很多，怎麼成文|research-writing、citation-audit 等形成學術論證並核對引用|讀真正章節與前後修訂；助理回讀產物再引導下一步|

這支影片8:51.506，以同一銀行案例保留選題失敗與轉向、共同樣本比較及寫作修訂。它不是讓每篇論文都硬用43個skill的清單，也不代表 native Codex discovery/invocation 已通過。畫面是教學角色問答與真實瀏覽器閱讀產物的取材；操作連結不是後製補造。影片保留當時待編譯畫面，Release所附30頁PDF是後續真正LaTeX完成的成果。
